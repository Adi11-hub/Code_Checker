# Code_Checker
Code Checker AI is an AI-powered web application that helps developers analyze and review their source code. It uses Generative AI to identify potential bugs, code quality issues, security concerns, and possible improvements, making code review faster and easier.

Tech Stack...
Frontend: React.js
Backend: Node.js, Express.js
AI: Google Gemini API
API: REST API
Package Manager: npm

How It Works...
User enters or submits source code.
The frontend sends the code to the backend.
The backend processes the request and communicates with the Gemini AI API.
AI analyzes the submitted code.
The analysis is returned to the application.
User receives bugs, explanations, and improvement suggestions.
